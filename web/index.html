制作方式

适合透明 PNG 拆件、节点绑定和内置动作微调。已经烘焙在整张脸里的眼睛和嘴巴，需要先拆出，才能独立驱动。

通用骨架没有自动补画或角色专用网格。肩颈接缝、裙摆遮挡和坐姿需要看图调整；自动绑定仅提供起点。

所有工具代码、官方 kit、示例、项目和导出结果均在本目录。运行只需要系统 Python 3.10+ 和现代浏览器，无需 npm 或联网。
