# 角色工程台 Agent Skill

通过角色工程台的同一数据和构建链路完成用户要求。用户手动确认的坐标、尺寸、角度、层级和动作是制作依据；不要为“优化”重新拟合其他表情或改动未要求的动作。

## 定位工程与运行服务

- 优先使用用户指定的工具目录。本 Skill 随工具放在 `skills/character-studio/`，工具根目录为该文件夹上移两级；若 Skill 被单独安装，则从用户提供的目录或当前工作目录查找 `VERSION.json`，确认 `app` 为 `character-studio`。不写死盘符、工程目录名或端口。
- 先读工具根的 `README.md`。执行 `python -S launch.py --no-open`，使用它返回的实际 URL；用 `GET /api/health` 确认 `root` 指向本工具，避免连接另一份工具台。
- 从 `GET /api/projects` 找到目标工程。每个工程 API 请求都显式附带 `?project=<工程ID>`。修改前读取该工程的 `project.json`、`assembly-v4.json`、`rig.json`；需要合成运行模型时使用 `studio_core.effective_model(project_path)`。
- 内置显示名 **老酸奶** 对应稳定工程 ID `xitelali-2-1-0`。显示名不等于目录名、包 ID 或部件 ID；重命名显示名时不要连带改路径或几何。whale 是另一份独立参考工程。

## 选择正确模式

- `source-pack/` 是导入形象包的历史原件。原包预览／导出使用其原代码；编辑副本使用工具台的基础或高级部件运行时。不要用通用运行时覆盖原包来“保留原效果”。
- 新角色或尝试性改动应建立新工程或复制工程；用户明确要求修改当前工程时，在当前工程内完成指定修改。
- 表情、轮廓眼睑、眨眼端点、专用坐姿和跟随物理使用 `layered` 高级模式；基础 `generic` 模式不应用这些配置。高级动作需有近／远腿及所需语义节点绑定。
- 需要进一步了解字段、单位、保存入口或原包处理时，读 [工程与接口契约](references/project-contract.md)，不要参照旧的一次性制作脚本猜测。

## 素材、组装与绑定

- PNG 先复制导入工程，再登记部件。移动、尺寸、旋转、层级、隐藏和固定写入装配；骨架父子、pivot 和部件归属写入 `rig.json`。
- 部件名称可以是任意合规名称。眼白、虹膜、眼睑／睫毛、眉毛、嘴及近／远侧由配置决定，不假设 `part_27` 或任何特定文件名具有固定意义。
- 使用工具的重命名接口或 `studio_core.rename_part`，使图片、绑定、表情布局和角色映射同步更新。不要只改 PNG 文件名。
- 已有整合睫毛／眼睑贴图可直接绑定；不要擅自替换为新眼睛、压扁虹膜或修改眼白大小。需要新图时按用户要求另行生成或导入，此 Skill 不提供在线绘图连接。

## 表情与眨眼校准

- 表情页面：`/p/<ID>/calibration.html?scope=expression&state=<表情>`；眨眼页面：`?scope=blink&phase=start` 或 `phase=end`；坐姿页面：`?scope=seated`。功能映射位于 `/p/<ID>/features.html`。
- 用户要手动组装时，打开对应页并保留可继续编辑的入口。等用户完成保存后，以磁盘保存结果为准；截图不能替代精确保存值。
- `assembly-v4.json` 的 `expressionLayouts`、`authoredLashTransitions`、`blinkCalibration` 是已保存校准的优先来源。只更新本次涉及的表情、眼侧和端点；不要将一个表情复制覆盖全部布局。
- 日常眨眼近／远侧各有独立 `start`、`end`。修改终点时保留起点；修改一侧时保留另一侧。中间位置、大小与旋转由现有 smoothstep 插值补全，睫毛和轮廓遮罩共用变换。
- 四项已有表情过渡保留各自起点与用户校准终点。眉毛已有手动摆位时，不再叠加额外静态偏移；只有用户启用“叠加运动”才使用对应运动配置。
- 替换表情的近眼、远眼和嘴可以分别指定，也可以明确保留原部件。例如只改惊讶嘴型，不代表可以改惊讶眼睛。

## 坐姿、物理与动作

- 坐姿替换图、被替换的原部件、层级、渐变范围、身体下移是独立配置。坐姿改动不应改变提起、拖拽、落地等其他动作，除非用户要求。
- 物理按后发、刘海、缎带、裙摆分组，设置根部、末端、增益、弹性和阻尼。缺少配置时保持关闭，不替其他角色照搬示例的像素坐标。
- “眩晕身体固定、仅头部及子节点运动”是动作选项。老酸奶示例不恢复已取消的新增头部鼠标追踪。
- 动作预览使用 `/p/<ID>/motion/?manual&pose=<动作或表情>`，支持暂停、逐帧、时间轴和左右朝向。编辑后重载已保存工程，确认实际运行画面。
